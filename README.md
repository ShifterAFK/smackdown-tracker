# AFK Journey Smackdown Tracker

Unofficial community draft tracker for AFK Journey Smackdown.

- Record completed matches
- Browse hero, duo and Phantimal statistics
- Use the draft assistant
- View map rotation information

This is an unofficial community tool. AFK Journey artwork belongs to its respective owners; no affiliation or endorsement is implied.

## Deployment

Deploy the repository as a GitHub Pages site using the `main` branch and root directory. The entry point is `index.html`.
